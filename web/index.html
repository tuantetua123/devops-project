Hướng dẫn sử dụng

  1. Kết nối bằng Admin API Key.
  2. Tạo hoặc chọn lớp học.

  4. Sinh viên quét QR bằng điện thoại.
  5. Theo dõi kết quả ở bảng bên dưới.
